## 学到的概念

### 计算机基础
1. Motherboard 是计算机的主电路板，承载内存与连接器，并把运行计算机所需的部件组织到同一硬件系统中。

2. CPU 负责执行指令和进行计算；RAM 是供 CPU 使用的临时存储位置。二者分别对应处理与短期工作数据。

3. HDD 与 SSD 都用于持久保存数据。HDD 被描述为断电后仍保存数据的永久存储位置；SSD 使用 non-volatile flash memory，可以替代 hard drive。

4. PSU 把墙上插座提供的电转换为计算机可使用的形式；GPU 负责在计算机屏幕上渲染视觉内容。

5. ISP 是提供互联网接入的公司，接入类型包括 dial-up、DSL、cable、fiber-optic 和 satellite。

6. 安全登录计算机的方式包括使用 strong password、启用 two-factor authentication，以及使用 password manager。

7. IDE 帮助开发者高效地编写、测试和调试代码；code editor 用于编写和调试代码。两者在功能描述上有重叠，但 IDE 的定义还明确包含测试与一体化效率。

8. Git 是 version control system，用于跟踪代码变化并支持多人协作；repository 则是保存项目文件和版本历史的存储位置。GitHub、GitLab 和 Bitbucket 是常见的云端 repository hosting services。

9. Package manager 简化 libraries 和 project dependencies 的添加、更新与删除，示例包括 npm、pip 和 Maven。

10. Software testing 用于确认代码是否按预期工作；Jest、PHPUnit 和 JUnit 是 testing libraries 或 frameworks 的示例。

11. 文件名应当易于理解和维护。`about-us.html` 比 `page1.html` 更能表达文件内容，命名本身构成项目可读性的一部分。

12. Root directory 是文件系统的顶层目录，directory 与 folder 在这里表达同一概念。Explorer 和 Finder 分别是 Windows 与 macOS 的文件管理器，可以创建、移动、删除和搜索文件或文件夹。

13. Markdown 是常用于 documentation 和 README 的 markup language；README 保存项目说明，例如安装方法和使用方法。`index.html` 表示用户访问网站时默认显示的页面。

14. `.html`、`.css`、`.js` 分别标识 HTML、CSS 和 JavaScript 文件。文件扩展名提供了文件类型及其用途的直接线索。

15. 常见图片与图形格式包括 JPEG、PNG、支持动画的 GIF，以及用于 vector graphics 的 SVG。常见音视频格式包括 MP3、MP4 和 Apple 开发的 MOV。

16. 常见字体格式包括 TTF、WOFF 和 WOFF2；WOFF2 是 WOFF 的后继格式并提供更好的压缩。ZIP 用于压缩文件和文件夹。

17. Web browser 是访问和查看互联网网站的软件应用，Google Chrome、Mozilla Firefox 和 Microsoft Edge 是常见示例。Search engine 是检索互联网信息的工具，Google、Bing 和 Yahoo 是示例。浏览器与搜索引擎承担不同功能，不能视为同一概念。

18. 搜索可以通过语法缩小或调整范围：`site:` 把结果限制在指定网站，`filetype:` 按扩展名寻找文件，减号排除包含某个词的结果，加号用于包含某个搜索词。

### HTML基础
1. HTML代码基础模板：
`<!DOCTYPE html>`
`<html lang="zh-CN">`
    `<head>`
        `<title></title>`
        `<meta charset="UTF-8">`

    `</head>`
    `<body>`
        `<section>`
            `<h1></h1>`
            `<h2></h2>`
            `<p></p>`
        `</section>`
        `<section>`
            `<h2></h2>`
            `<ul>`
                `<li></li>`
                `<li></li>`
                `<li></li>`
            `</ul>`
        `</section>`
    `</body>`
`</html>`

2. 引用路径：`<a href="路径">文字</a>`；需要新标签页时使用 `target="_blank"`。
3. 有/无序列表`<ul>  <li></li> </ul>` 与`<ol> <li></li> </ol>`
## 遇到的问题
`posts` 中返回报错
### 问题现象
无法找到对应路径而报错
### 原因
`posts` 中返回首页的相对路径缺少 `../`
### 解决过程

当前文件位于 posts 子目录，直接写 index.html 会寻找
posts/index.html。使用 ../ 返回上一级目录，因此首页路径应为
../index.html。
